## SECTION 6: WHAT CLAUDE CANNOT DO (HONEST LIMITATIONS)

1. **Claude cannot browse the web in real-time** -- You must feed it information
2. **Claude cannot execute code on its own** -- You run everything
3. **Claude cannot guarantee code correctness** -- Always test
4. **Claude cannot make investment decisions** -- It analyzes, you decide
5. **Claude cannot replace domain expertise** -- It amplifies YOUR knowledge
6. **Claude cannot maintain context across sessions** -- You must re-brief for complex projects (use system prompts and project files)
7. **Claude's output needs editing** -- Raw Claude content is detectable and often generic. Your expertise makes it valuable.
8. **Claude API costs add up** -- Budget ~$10-50/mo for API usage beyond Pro subscription
